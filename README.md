# PodBar

只显示 AirPods 电量的原生 macOS 菜单栏小工具。Swift + AppKit，无第三方依赖、无网络请求、无 Dock 图标。

菜单栏上下两行仅显示电量，上面是左耳，下面是右耳。字号保持 9.5 pt，横向宽度跟随较宽的一行，每侧只留 1 pt，并关闭系统自动追加的横向留白；100% 约占 31 pt，两位数约占 25 pt：

```text
100%
100%
```

点击可查看左右耳和充电盒电量、连接状态与读取时间，手动刷新，切换「登录时启动」。断连后菜单栏项目完全隐藏；再次连接后自动出现。隐藏时，在 Finder 或 Spotlight 中重新打开 PodBar 可在鼠标位置呼出菜单，仍可刷新、修改登录启动设置或退出。

按住 **⌘ Command** 拖动菜单栏里的 PodBar，可放到系统电池旁。系统不提供把第三方菜单栏项目自动固定到电池旁的公开 API；拖动位置会由系统保存。

## 构建与安装

需要 macOS 13 或更新版本，以及 Xcode / Command Line Tools（Swift 5.10+）。在本项目目录执行：

```bash
swift test
./Scripts/package_app.sh
./Scripts/install.sh
```

构建产物位于 `build/PodBar.app`，安装脚本默认安装到 `/Applications/PodBar.app` 并启动。也可传入 `"$HOME/Applications/PodBar.app"` 使用个人应用目录。已有同标识 PodBar 会被备份后替换，不替换其他同名应用。构建采用本机 ad-hoc 签名，适合本人使用；不含 Developer ID 签名或公证。

首次启动后，在菜单里开启「登录时启动」即可；若 macOS 要求确认，菜单会提示到系统设置中允许。

## 电量与刷新

- 通过系统自带的 `/usr/sbin/system_profiler SPBluetoothDataType -json -detailLevel basic` 读取，不主动连接耳机、不扫描蓝牙广播，不需要管理员权限。
- 已连接时每 60 秒读取一次；未连接或读取失败时每 120 秒尝试一次。打开菜单且距上次读取超过 15 秒会立即刷新。定时器允许 5 秒合并调度以减少唤醒。
- 通过系统 IOBluetooth 连接/断开通知立即触发额外查询：收到断开事件先清掉对应设备的电量并隐藏（若另一副耳机仍连接则显示另一副），连接事件立即查询。若连接早于系统电量更新，每隔约 2 秒补查，最多 3 次，然后恢复正常间隔。事件监听不扫描蓝牙、不主动连接或断开设备。
- 若 macOS 弹出蓝牙权限请求，允许 PodBar 以启用事件监听；未能接收事件时仍保留上述定时查询。
- 每次读取在后台执行，设置 12 秒超时；进程不响应退出时会结束该子进程。系统休眠时取消查询，唤醒后约 2 秒重新读取。
- 未连接、关闭蓝牙、休眠或查询失败时完全隐藏菜单栏项目，后台继续按上述间隔检查（休眠时暂停）。已连接但缺少单侧电量时，仅缺少的那一行显示 `--`，不沿用上一次电量，不会把整体电量复制成左右耳电量。
- 数据是 **macOS 最近报告的值**。查询时间不等于耳机实际测量时间。特别是充电盒合盖后，系统可能不再更新盒子电量。PodBar 无法从系统报告中取得每项电量的测量时间。
- 正常收到连接/断开事件时无需等待 60 / 120 秒的定时查询；实际响应取决于系统通知送达和电量数据何时可用。若系统没有发送事件，定时查询仍会纠正状态。也可重新打开 PodBar 立即刷新。
- 支持 AirPods 名称识别，以及已知 Apple 产品 ID / 左右耳字段识别，因此用户这副改名后的 AirPods Pro 2 也可识别。多副耳机时优先显示已连接设备，其次名称含 Pro 的设备，最后按设备标识固定排序。

## 诊断与维护

```bash
./build/PodBar.app/Contents/MacOS/PodBar --diagnose
# 被动观察 120 秒的连接/断开事件（不改变连接）：
./build/PodBar.app/Contents/MacOS/PodBar --watch-connections
```

诊断只打印设备名称、连接状态和电量，不输出地址或序列号。应用不写电量日志、不持久化蓝牙报告。若终端运行受沙盒限制，系统可能返回空蓝牙数据；应以正常启动的 `.app` 或不受该限制的终端结果为准。

- `Sources/PodBarCore`：蓝牙 JSON 解析、子进程超时与取消。
- `Sources/PodBar`：AppKit 菜单栏、菜单、休眠处理、登录项。
- `Tests/PodBarCoreTests`：真实字段样本、断连缓存、缺失值、非法电量、改名设备、超时与取消等回归检查。
- `Scripts`：原生图标生成、打包与安装。用 Xcode 打开 `Package.swift` 可继续维护。

长期不使用时可从菜单关闭登录启动并退出，再删除应用；源码项目独立保留。项目隐藏时，重新打开 PodBar 即可呼出菜单。
